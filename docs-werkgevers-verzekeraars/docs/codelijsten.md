# SIVI Codelijsten Verzuim

Dit koppelvlak leunt op de centrale **SIVI Codelijst Verzuim (Release 2026)**.

---

## Codelijst Meldingstypen
| Code | Omschrijving | Betekenis |
|:---|:---|:---|
| `01` | Eerste verzuimdag | Initiële melding van arbeidsongeschiktheid |
| `02` | Gedeeltelijk herstel | Wijziging in het percentage werkhervatting |
| `03` | Volledig herstel | 100% hervatting van de werkzaamheden |
| `04` | Correctie | Wijziging van een eerdere melding |

---

## Codelijst Vangnetbepalingen
| Code | Omschrijving |
|:---|:---|
| `01` | Orgaandonatie |
| `02` | Zwangerschap en bevalling |
| `03` | No-riskpolis (WIA/Doelgroep) |
| `99` | Geen vangnet |
